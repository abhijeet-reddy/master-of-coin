#### 2.2 Implement Trading 212 provider

- [x] Create `backend/src/services/investment_provider/trading212.rs`
  - `Trading212Provider` struct with `reqwest::Client`
  - Implement `InvestmentProvider` trait
  - `provider_type()` returns `InvestmentProviderType::Trading212`
  - `get_portfolio_value()`:
    1. Extract `api_key` and `api_secret` from credentials JSON
    2. Build `authWithSecretKey` Basic Auth header: `Authorization: Basic base64(api_key:api_secret)`
    3. Determine base URL from credentials (`environment` field: "live" or "demo", default "live")
    4. Call `GET /api/v0/equity/account/cash`
    5. Parse response: extract `total`, `free`, `invested`, `pieCash`
    6. Calculate `stock_value = total - free + pieCash` (stock positions only, excludes uninvested cash)
    7. Return `PortfolioSnapshot { stock_value, invested_amount: invested, currency, timestamp }`
  - Handle rate limit headers (`x-ratelimit-remaining`, `x-ratelimit-reset`)
  - Map HTTP errors to `InvestmentProviderError` variants (401 → AuthenticationFailed, 429 → RateLimited, etc.)

### Phase 3: Portfolio Sync Service

#### 3.1 Create portfolio sync service

- [ ] Create `backend/src/services/portfolio_sync_service.rs`
  - `execute_portfolio_sync()` free function (same pattern as `drift_detection_service::detect_drift`)
    1. Parse input JSON to get optional `account_id`
    2. Query `investment_providers` for the user (filtered by account_id if provided)
    3. For each active provider:
       a. Decrypt credentials using `encryption::decrypt_credentials()`
       b. Look up provider implementation by `InvestmentProviderType`
       c. Call `get_portfolio_value()` with retry logic (exponential backoff, 3 attempts)
       d. Calculate current account balance via `repositories::account::calculate_balance()`
       e. Compute delta = provider_value.stock_value - current_balance
       f. If |delta| > 0.01, create adjustment transaction titled "Portfolio Value Adjustment"
       g. Build `AccountSyncResult`
    4. Return `PortfolioSyncReport` as JSON (stored in `background_jobs.result`)
- [ ] Add `pub mod portfolio_sync_service;` to `backend/src/services/mod.rs`
